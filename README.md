# labor-cost-bot

Телеграм-бот для упрощённого выставления трудозатрат на корпоративном портале.
Бот сам ходит на портал под учёткой сотрудника, показывает, за какие дни ещё не
проставлены трудозатраты и позволяет проставить их прямо из чата с ботом.

Бот рассчитан на использование только одним пользователем - владельцем аккаунта.

## Возможности

- **`/info`** - сводка по трудозатратам: сколько дней осталось заполнить и по
  каким проектам.
- **Режим «Проставить дни»** - интерактивное заполнение ТРЗ прямо в сообщении, имеется
  возможность выставить определенное произвольное количество % ТРЗ для каждого проекта.
- **Ежедневное напоминание** по заполнению ТРЗ если есть незаполненные дни.

## Конфигурация

Нужно собрать .env файл с переменными:

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `TG_USER_ID` | Telegram ID единственного разрешённого пользователя |
| `PORTAL_LOGIN` | Логин на портале |
| `PORTAL_PASSWORD` | Пароль на портале |

## Запуск в Docker

```bash
docker build -t labor-cost-bot .

docker run -d --name labor-cost-bot \
  --env-file .env \
  labor-cost-bot
```
